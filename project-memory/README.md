# project-memory — 项目记忆（跨 agent 通用）

本目录是本仓库的**权威项目记忆**，供任何 AI 编码助手（agent）使用，不绑定特定工具或会话系统。

## 会话约定（任何 agent 遵循）

1. **会话开始**：通读本目录全部 `YYYY-MM-DD.md`（按日期升序），掌握项目现状、历史决策与已知坑位，再开始工作。
2. **完成实质工作后**：当日无 `YYYY-MM-DD.md` 则创建，有则在末尾追加。只记录有长期价值的事实——技术方案与取舍、根因结论、里程碑、约定变更；不记录临时排查噪音（一次性报错、中间路径等）。
3. **双写同步**：若所用 agent 有私有记忆目录（如 `.workbuddy/memory/`），可按其自有格式照常工作，但**会话结束前必须将当日日志同步复制到本目录**。两处不一致时，以本目录为准。
4. **决策记录**：重大决策（架构/选型/目录结构/发布配置等）走 `zh-docs/decision_log.md` 的 DR 编号流程；本目录只做事实日志，不复述决策全文。
